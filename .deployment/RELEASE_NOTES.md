# ZohaOnline v0.3.0

Real runtime index builder release.

- Admin builder now reads and writes the runtime taxonomy model.
- Left tool rail has Elements and Settings tabs and can collapse.
- Real taxonomy term search, create, edit, deactivate and reactivate are included.
- Preview uses the production IndexRuntimePanel.
- Content Types links directly to the builder for each runtime-backed post type.
- The separate legacy Labels navigation item is removed.
- No database schema migration is required.
