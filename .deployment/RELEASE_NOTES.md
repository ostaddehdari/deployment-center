## نمایه‌ساز مرجع اصلی و نمایه‌های درختی

- والد «زیرموضوع» و «کلید پردازش»: موضوع؛ نمایش والد و مسیر در طراحی و تنظیمات.
- نمایه اصلی به‌علاوه سه سطح زیرشاخه؛ کنترل دور، والد ناموجود و عمق اضافی در API.
- حذف انتخاب «نمایه متصل»؛ هر فیلد هویت و فهرست خودش را در نمایه‌ساز تعریف می‌کند.
- API کاربر و تصویر سازگار بخش‌های قدیمی از تعریف منتشرشده نمایه‌ساز می‌خوانند؛ بازگشت به ساختار قدیمی حذف شد.
- حفظ نسخه‌های پیشین، ویرایش مستقل پیش‌نویس و شناسه واژگان؛ پاک‌شدن انتخاب زیرشاخه‌ها هنگام تغییر والد.
- نصب از commit تأییدشده v0.5.0/v0.5.1؛ پشتیبان‌گیری PostgreSQL 17 و بازگردانی فایل‌ها/build/اشاره‌گرها در صورت خطا پیش از commit.

اعتبارسنجی: ۲۰ تست رفتاری تولباکس و سلسله‌مراتب، بررسی TypeScript و Vue، آزمون تراکنشی مهاجرت و سرویس‌های واقعی روی PostgreSQL تعبیه‌شده، و مرورگر واقعی با API آزمایشی برای روابط، ذخیره تنظیمات، انتشار و پاک‌شدن انتخاب وابسته. تست کامل و build واقعی پروژه در نصب سرور اجرا می‌شوند.
