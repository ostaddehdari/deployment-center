## دامنه مشترک کلید پردازش با مرجعیت نمایه‌ساز

- خطای `no global processing-key items found` نسخه ۰.۶.۵ حذف شده است؛ نصب به وجود آیتم بدون والد تاریخی وابسته نیست.
- «کلید پردازش» در بوم طراحی و تنظیمات همچنان فرزند «موضوع» و دارای تو‌رفتگی درختی است.
- تنظیم جدید «دامنه آیتم‌ها» داخل نمایه‌ساز تعیین می‌کند آیتم‌ها به والد وابسته باشند یا برای همه والدها مشترک باشند.
- `IDX-003` در نسخه فعال و پیش‌نویس روی دامنه مشترک قرار می‌گیرد؛ بنابراین «آثار و محاسن»، «پیامد و عواقب»، «راهکار»، «وظایف» و سایر آیتم‌های فعال برای موضوع سیستمی یا شخصی نمایش داده می‌شوند.
- API کاربر، پیش‌نمایش مدیریت، مدیریت آیتم‌ها و ایجاد آیتم شخصی همگی تنظیم منتشرشده نمایه‌ساز را می‌خوانند.
- مهاجرت، خود واژگان را تغییر نمی‌دهد و اثرانگشت آن‌ها پیش و پس از اجرا کنترل می‌شود.
- نصب‌کننده از سورس، buildهای API و وب و تنظیمات دیتابیس پشتیبان می‌گیرد و rollback کامل دارد.
- تست‌های قرارداد، build پاک دو برنامه، سلامت OTP داخلی و عمومی، assetهای Nuxt و پایداری هر دو سرویس بررسی می‌شوند.

پیش‌نیاز: نصب موفق ۰.۶.۴ و commit `d11644e9a01f561120b7ed5e76601f2841d6a806`. نسخه ۰.۶.۵ به علت توقف در پیش‌بررسی نباید تغییری در سرور ایجاد کرده باشد.
