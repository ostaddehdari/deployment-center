## نمایه‌های تکرارشونده و آکاردئون‌های تو‌در‌تو

- تنظیم عمومی «تکرارشونده همراه با زیرنمایه‌ها» به تنظیمات نمایه‌ساز اضافه شده است.
- موضوع‌ها و کلیدهای پردازش در نمایه‌گذاری کاربر به‌صورت آکاردئون‌های تو‌در‌تو نمایش داده می‌شوند.
- هر موضوع می‌تواند چند کلید پردازش داشته باشد و برای هر کلید توضیح مستقلی ذخیره شود.
- `IDX-001` و `IDX-003` تکرارشونده و توضیح `IDX-004` مستقیماً زیر کلید پردازش قرار می‌گیرد.
- داده‌های قبلی به اولین کلید پردازش تبدیل می‌شوند و قالب سازگار قدیمی نیز هنگام ذخیره حفظ می‌شود.
- مهاجرت، واژگان و payloadهای ذخیره‌شده کاربران را تغییر نمی‌دهد و اثرانگشت هر دو قبل و بعد از نصب کنترل می‌شود.
- نصب‌کننده از سورس، buildهای API و وب و تنظیمات فرم‌های فعال/پیش‌نویس پشتیبان می‌گیرد و rollback کامل دارد.
- تست قراردادها، build پاک، سلامت OTP داخلی و عمومی، assetهای Nuxt و پایداری سرویس‌ها بررسی می‌شوند.

پیش‌نیاز: نصب موفق `zohaonline-v0.6.6`. چون commit نسخه ۰.۶.۶ هنگام نصب روی GitLab ایجاد شده، نسخه ۰.۶.۷ برابری HEAD محلی و remote را همراه با hash دقیق فایل‌های نسخه قبل کنترل می‌کند.
