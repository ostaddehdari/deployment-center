# رفع فایل اجرایی API در نسخه ۰.۶.۱

مخصوص نصب موفق ۰.۶.۰ با commit 9b317ca2967bb2929d5eeaf042f3cca3522cebf0 و خطای Cannot find module apps/api/dist/main.js است.

بسته از تنظیمات build و خروجی موجود پشتیبان می‌گیرد، کامپایل افزایشی را در تنظیمات build API غیرفعال می‌کند و کنترل فایل اجرایی را به فرمان build اضافه می‌کند. اگر فایل main در زیرپوشه dist تولید شده باشد، یک ورودی کوچک آن را با حفظ مسیر importهای نسبی اجرا می‌کند. خروجی فاقد main معتبر پذیرفته نمی‌شود.

سپس API کامل build می‌شود و تست‌های پروژه اجرا می‌شوند. تأیید نصب به پاسخ JSON اعتبارسنجی درخواست خالی OTP و ثابت‌ماندن فرایند API وابسته است. این درخواست گیرنده‌ای برای پیامک ندارد. دیتابیس، فرم‌ها و build وب تغییر نمی‌کنند.

این بسته سورس تنظیمات build و کنترل خروجی را پس از موفقیت در GitLab ثبت می‌کند. در صورت شکست پیش از commit، تغییرات متعلق به بسته بازگردانده می‌شوند.
