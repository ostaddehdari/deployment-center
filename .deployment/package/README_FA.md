# ضحی آنلاین ۰.۶.۰

نمایه‌ساز مرجع تعریف نمایه، عنوان، ترتیب و والد است. نسخه منتشرشده فرم مبنای API کاربر و جدول‌های سازگار با بخش‌های قدیمی می‌شود. جدول واژگان موجود برای حفظ شناسه و داده آیتم‌ها نگه داشته شده است؛ انتخاب و اتصال به یک تعریف بیرونی از رابط حذف شده است.

موضوع، والد زیرموضوع و کلید پردازش است. بوم طراحی مسیر و والد را نمایش می‌دهد. هر نمایه اصلی تا سه سطح زیرشاخه دارد؛ تنظیم والد، افزودن فرزند، تو‌رفتگی و بیرون‌رفتگی در دسترس است. وابستگی در پیش‌نمایش و فرم کاربر نیز اعمال می‌شود و تغییر والد انتخاب تمام زیرشاخه‌ها را پاک می‌کند.

فهرست آیتم‌های هر نمایه از تنظیمات خودش مدیریت می‌شود. آیتم‌های تاریخی بدون والد مشخص، پس از انتخاب والد به‌صورت عمومی قابل استفاده باقی می‌مانند تا مدیر آن‌ها را دسته‌بندی کند. ساختار و فیلدها فقط با انتشار تغییر می‌کنند. تغییر آیتم‌های فهرست همانند قبل بلافاصله در دسترس است.

پیش‌نیاز: نصب موفق ۰.۵.۱، شاخه feature/zoha-public-site-v1 و commit a6188cd58bdbf68865f37dab78f6f5b1dc4efb27. فایل‌های متعلق به بسته نباید تغییر ثبت‌نشده داشته باشند. بسته، تست کامل پروژه و هر دو build را روی سرور اجرا می‌کند. سپس سرویس‌ها کوتاه‌مدت متوقف می‌شوند، پشتیبان داده‌ها با pg_dump سازگار گرفته می‌شود و فقط مهاجرت ۲۰۰ اعمال می‌شود. نسخه‌های فعال و پیش‌نویس قبلی، فیلدها، گزینه‌ها، قواعد و شناسه آیتم‌ها حفظ می‌شوند.

پیش از commit در صورت خطا، فایل‌ها و build قبلی و در صورت نیاز اشاره‌گر نسخه‌ها و تصویر سازگار دیتابیس بازگردانده می‌شود. نسخه‌های تازه ایجادشده برای بررسی باقی می‌مانند. اگر پس از commit، push شکست بخورد، سرویس نصب‌شده فعال می‌ماند و دستور تلاش مجدد چاپ می‌شود.
